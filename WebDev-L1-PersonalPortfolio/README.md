## Features

- Responsive portfolio design (mobile, tablet, laptop and desktop)
- Profile photo in a modern circular frame
- Sticky navigation bar with CSS smooth scrolling
- About section
- Skills section (Frontend, Backend, Database, Tools)
- Education section (CSS timeline card)
- Projects section with hover effects and live demo links
- WhatsApp contact button (`https://wa.me/917408164088`)
- Direct email button (`mailto:anandsingh32871@gmail.com`)
- GitHub link
- LinkedIn link
- CV download option (HTML `download` attribute)

### CSS techniques used

- CSS custom properties (design tokens)
- Flexbox and CSS Grid layouts
- Media queries for responsive design
- CSS transitions, hover effects and keyframe animations
- Semantic HTML5: `nav`, `header`, `main`, `section`, `article`, `footer`
- Respects `prefers-reduced-motion`
