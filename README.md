## 📖 Project Description

The **CodeCraft Studio Landing Page** is a single-page website that introduces a modern digital agency and its services. It features a dark, premium design with a warm amber-to-coral accent palette, bold typography and a clean visual hierarchy.

The page guides visitors from a striking hero section, through the agency's services, story and key strengths, to a prominent call-to-action and a contact section with real developer details and social links. Every layout, hover effect, animation and the responsive navigation is implemented purely with CSS — the page works by simply opening `index.html` in a browser.

---

## 🛠️ Technologies Used

- **HTML5** – semantic structure (`header`, `nav`, `main`, `section`, `article`, `footer`)
- **CSS3** – Flexbox, CSS Grid, custom properties, media queries, transitions and keyframe animations

> ✅ **Built using ONLY HTML5 and CSS3. Absolutely no JavaScript or frameworks.**

---

## ✨ Features

- **Fixed navigation bar** with brand logo and anchor links to Home, Services, About, Why Us and Contact
- **CSS smooth scrolling** (`scroll-behavior: smooth`) with `scroll-padding-top` so headings are never hidden under the fixed navbar
- **Responsive navigation** that reflows into a compact two-row layout on mobile (no JavaScript)
- **Hero section** with headline, subheadline, "Start Your Project" CTA button and a CSS-only browser mock-up illustration with floating badges
- **Services section** with 3 cards (Web Development, UI/UX Design, Digital Solutions), each with an icon, title, description and hover effects
- **About Us section** describing what the agency does, its mission, focus on modern technology, user-friendly experiences, quality and creativity
- **Why Choose Us section** with 4 feature cards (Modern Technology, Creative Solutions, Responsive Design, Quality Focus)
- **Call-to-Action section** – "Have a Project in Mind?" with a "Get Started" button
- **Contact & Social section** with real developer details, a clickable email link and clearly labelled **GitHub** and **LinkedIn** buttons that open in a new tab (`target="_blank" rel="noopener noreferrer"`)
- **Professional footer** with brand, email, GitHub, LinkedIn and copyright information
- One consistent colour palette defined with CSS custom properties
- Fluid, responsive typography using `clamp()`
- CSS-only hover effects, smooth transitions, shadows and rounded corners
- Inline SVG icons with accessible labels
- `prefers-reduced-motion` support for accessibility
- Global `box-sizing: border-box` and no horizontal scrolling on any screen size

---

## 📱 Responsive Design

The website is **fully responsive** and designed for:

- 📱 **Mobile** (≤ 480px and ≤ 720px)
- 📲 **Tablet** (≤ 960px)
- 💻 **Laptop** (≤ 1100px)
- 🖥️ **Desktop** (> 1100px)

Responsiveness is achieved with CSS Grid, Flexbox, fluid `clamp()` sizing and CSS media queries.
